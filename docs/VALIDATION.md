# 验证记录

状态：开发预览，真实游戏联机及渲染验收未完成。开发环境为 Linux/.NET 8，不能替代 Windows 游戏客户端与专用服。

参考程序集来自 LuaCs 官方发布包 `luacsforbarotrauma_refs.zip`，SHA-256：

`0fcf87af80a33575346a959b29f9f1af9e8c3f6f569974e35ab56007d5cdb487`

下载的实际运行时程序集显示 Barotrauma 与 DedicatedServer 版本均为 **1.13.5.0**。通过只读反射探测检查 LuaCs 单例、网络服务、Start/Send/Receive、CoroutineManager 更新签名，以及客户端聊天列表字段和人物绘制入口。没有启动游戏或 GPU。

## 自动化覆盖

- 客户端/服务器分别对真实 LuaCs 参考程序集编译。
- Python 导入器：静图缩放、透明度预乘、GIF disposal/动画差异、时间保持、帧数上限、格式/尺寸/体积限制、链接及截断拒绝。
- Python 生成资源，由 C# 实际解压并校验，覆盖格式互通。
- 核心：完整性校验、非法头部/维度/帧数/延迟、超量解压、偏移溢出、乱序和重复块、内存预算、LRU、令牌桶、未授权下载和未请求资源、卸载清理。
- 协议模拟：零延迟及 800ms 往返延迟，注入丢包和重复包，检查资源完整传输及限速行为。
- 随机与带合法头部的畸形格式输入语料；最大像素数服务器验证的分配量与运行时间。
- 发布包白名单：不包含个人表情、索引、游戏文件、临时目录或凭据。
- Windows CI：独立导入 EXE 构建、实际导入合成静图/GIF、客户端/服务器编译、发布包生成。

本地与 CI 的具体运行结果在执行完成后记录于 `RESULTS.txt`。其中模拟时间和局部验证耗时不代表实际网络速度、游戏帧率或整局 CPU/GPU 占用。
