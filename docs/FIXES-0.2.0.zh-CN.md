# 0.2.0：独立面板与纯图片聊天

- F8 在游戏内打开自绘面板：统一圆角、深色卡片、蓝色选中态、名称搜索、最近发送、预览和发送按钮。窄窗口隐藏侧边预览，选择后仍可发送。刷新按钮重新读取导入库。
- 面板不使用原版 GUIMessageBox 的标题栏、按钮皮肤或卡片皮肤。原版基础控件仅提供输入、焦点和滚动；背景、卡片、按钮和滚动指示器独立绘制。
- 图片消息在 GameClient.AddChatMessage 的最高优先级前置钩子消费，早于 Lua 聊天事件、翻译、聊天标签和原生气泡。聊天栏、折叠提示、大厅和头顶只创建图片，不创建文件名、发送者或时间文字。普通聊天保留原流程。
- 原版距离/电台干扰会损坏图片标识。服务端跟踪当前路由，只丢弃损坏的图片消息，不放宽听力、私聊或死亡频道权限。有效图片仍严格验证发送者已上传及收件权限。
- 不增加服务器带宽、缓存和解码预算。面板使用一张 16 KiB 圆角遮罩，绘制时只加载可见缩略图，不新增服务器 UI 工作。缩略图与聊天共用已有纹理；最近发送仅内存保存 24 项。

公开参考仓库 HakureiReimu18/Touhou_Lua_Patch 的当前 main 未找到用户指定的「猪猪表情包」实现。本次未复制其源码或图片。面板由本项目独立实现；没有声称已经复现该特定组件。

自动检查涵盖传输/畸形输入、16 人分发限额、实际 1.13.5.0 原生钩子、纯图片行缩放与窄聊天窗、真实软件 GPU 动画回读及圆角绘制。UI 预览图使用生产圆角绘制器与原创合成表情，在离屏 GPU 渲染；它是外观示例，不是实际游戏截图。最终实际多人联机与其他模组组合需在用户本机验证。

升级时替换服务器与全部客户端的模组目录并重新加载插件。兼容现有 ECP 表情和协议 v2，旧端仍可能走旧文字显示链路。已有工坊 ID 3833045408，只更新此条目。
